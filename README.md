# Silk Knight - Hollow Knight Inspired Game

## Описание игры
Игра в стиле Hollow Knight с персонажем, у которого:
- Белая круглая голова
- Белые загнутые рожки как у козла (без разделения с головой)
- Узкая тёмно-синяя накидка
- Чёрные глаза как провалы в пустоту

## Управление
- **Z** - Прыжок (регулируемый, можно прыгать в воздухе за счёт шёлка)
- **X** - Атака шёлковой нитью (натягивается поперёк локации)
- **C** - Шёлковый рывок (кулдаун 0.2 секунды)
- **Стрелка вверх / W** - Подняться по лестнице
- **Стрелки влево/вправо или A/D** - Перемещение
- **F11** - Полный экран
- **ESC** - Выход

## Особенности
- Катсцена: персонажа сбрасывают из лаборатории в стеклянной колбе
- Город в стиле "Город слёз" из Hollow Knight (тёмно-синий, с дождём)
- Вода по краям платформы (можно плавать)
- Жучок на платформе посередине (нейтральный)
- Лестница для подъёма наверх
- HP бар (здоровье)
- Индикатор шёлка (восстанавливается на земле)
- Индикатор кулдауна рывка

## Запуск

### Из исходного кода (Python):
```bash
python main.py
```

### Как скомпилированная игра (Linux):
```bash
./dist/SilkKnight
```

### Создание .exe для Windows:
На Windows выполните команду:
```bash
pyinstaller --onefile --windowed --icon=icon.ico --name="SilkKnight" main.py
```
После этого в папке `dist` появится файл `SilkKnight.exe`

## Требования
- Python 3.8+
- pygame
- Для компиляции: pyinstaller

## Установка зависимостей
```bash
pip install pygame pyinstaller
```

## Цветовая палитра (City of Tears)
- Тёмно-синий фон: (20, 30, 60)
- Средне-синий: (40, 60, 100)
- Светло-синий (дождь): (80, 120, 160)
- Белый (персонаж): (255, 255, 255)
- Чёрный (глаза): (0, 0, 0)
- Тёмно-синяя накидка: (10, 20, 50)
- Вода: (60, 100, 140)
